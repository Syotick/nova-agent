## [0.1.0] - 2026-08-16

### 🎉 首个可运行版本

Nova Agent 诞生：一个"麻雀虽小五脏俱全"的 AI Agent 应用，对标 Claude Code 的最简实现。

### ✨ 新功能

**AI 对话核心**
- Agent 循环：AI 可以多步调用工具（最多 8 步），比如"先搜资料→再读文件→再总结"
- 多轮对话：AI 记得之前的对话内容，上下文完整
- 流式输出：回答像打字机一样逐字出现（SSE 技术）
- Markdown 渲染：标题、代码高亮、表格、引用都显示得漂漂亮亮
- 工具调用卡片：AI 每次调用工具，界面上实时显示输入/输出/耗时
- 轨迹视图：一次回答中每一步的完整时间线，可以"复盘"AI 怎么干活的
- 中断按钮：流式中途可停止，已生成内容保留

**多 Agent 管理**
- 可创建多个 AI 助手，各自独立配置（人设 + 模型 + 工具 + 技能）
- 侧边栏一键切换助手，删除助手连带清理它的会话

**可视化配置（非技术用户可用）**
- 技能管理页：表单化创建/编辑技能，不用碰文件
- 工具浏览页：所有工具按服务器分组展示，带参数说明
- API Key 配置：网页上 🔑 按钮即可设置，key 存在项目外

**会话管理**
- 会话新建/切换/重命名/删除
- 首条消息自动创建会话
- JSON 检查点持久化，崩溃不丢数据

**安全**
- 工作区隔离：AI 的文件工具只能访问 `workspace/`，摸不到项目代码和 key
- Key 外置：API key 存项目目录外
- 删除操作有确认弹窗
- Markdown 渲染禁用原始 HTML（防 XSS）

**体验**
- 深色玻璃拟态 + 紫蓝渐变界面（LobeChat 风格）
- 消息进出场/工具卡片展开/视图切换动画

### 🐛 修复
- （首个版本，暂无历史修复记录）

## [0.3.0] - 2026-08-16

### ✨ 新功能

**存储升级：JSON → SQLite**
- 数据库换成 Node 内置 SQLite（`node:sqlite`），零额外依赖
- 旧 JSON 数据**启动时自动迁移**，原文件备份到 `data/imported-json-backup/`
- 要求 Node.js 22+（旧版本 18+ 不再支持）

**定时任务系统（重大新能力）**
- 5 段 cron 定时任务：让 AI 定时干活（盯盘、日报、监控）
- 任务在**专用会话**中执行：每次执行都记得上次的上下文
- 支持手动立即执行、暂停/启用/删除
- 任务执行结果自动记录，网页可见
- 网页端新增"⏱️ 定时任务"管理页面

**后端模块化**
- 路由拆分：agents / sessions / chat / tasks / catalogs 五个独立文件
- `index.ts` 瘦身为"组装层"，只负责挂载和启动

**MCP 可靠性**
- 健康检查：真实 ping 探测工具服务器是否存活
- 自动重连：挂了按指数退避重连（5 秒 → 2 分钟，最多 20 次）

**CI/CD 强化**
- 新增 Release workflow：release-please 自动发版
- Conventional Commits 提交规范文档化

### 🐛 修复
- 修复 cron `*/5` 通配符匹配所有分钟的问题（单元测试发现）
- 修复改名后 API key 文件找不到的问题（自动迁移 key 文件）
- 修复 MCP 健康检查 Promise 恒真判断

## 未来计划（Roadmap）

- **虚拟滚动**：超长会话（>500 条消息）不再卡顿
- **多 Agent 编排**：主 Agent 派生子 Agent 并行干活并汇总（`POST /api/subagent`）
- **模型注册表**：不同 Agent 用不同模型（视觉/低延迟/长上下文）
- **SQLite 更大规模**：索引优化、查询能力增强
