# 🎓 终极验收项目：从零重写一个"最小 agent"

> 读完 8 篇指南 + 做完 8 课练习之后，这门课的最后一步：**不看 Nova Agent 的源码，自己写一个能跑的最小 agent**。
> 这不是给 Nova Agent 加功能（那会违背"功能冻结"），而是在你自己的目录里从零搭一个迷你版——用你自己理解的方式。

---

## 🎯 交付物

在一个新目录（建议 `playground/mini-agent/`）里，写一个**最小但五脏俱全**的 agent，满足：

- 能跟任意 OpenAI 兼容模型对话（`@ai-sdk/openai-compatible` 即可）
- 至少有 **1 个工具**能让 agent 调（建议先做一个"读文件"或"算数"）
- 用**你自己的话**写清楚每个文件在干嘛（这是关键：写注释就是教自己）
- 能跑起来、能对话、能调工具——**不依赖 Nova Agent 的 server/ 代码**

> 技术栈自选：Node + `ai` SDK 足够；愿意的话只用 Node 原生 fetch 调 API 也行。目标不是炫技，是**讲得清**。

---

## 🗺️ 里程碑（对应 8 篇指南）

每个里程碑都有"验收标准"——达到了再进下一个。

### M1 · 让它转起来（对应指南 01）
- 用 `streamText` + `tool()` 实现一个最小 agent loop：模型产出 → 执行工具 → 结果喂回 → 再产出，最多 3 步。
- 验收：能让 agent"先调工具再回答"，且你能**对着代码说出这 3 步循环在哪**。

### M2 · 让工具来自"外部"（对应指南 02）
- 用 `@modelcontextprotocol/sdk` 起一个 stdio MCP client，连接一个极简 MCP server（练习 02 写过）。
- 验收：工具清单从 server 拉取；server 进程死了 agent 不至于崩。

### M3 · 给 agent 一双手（对应指南 03）
- 加一个 `run_command` 工具：`spawn` 执行命令、收集 stdout/stderr、**超时杀进程树**。
- 验收：跑一个永不退出的命令（`node -e "setInterval(()=>{},1000)"`），它到超时会被终止且不留幽灵进程。

### M4 · 让它"会领域套路"（对应指南 04）
- 支持 `skills/<名>/SKILL.md`，解析 frontmatter，按需注入 system prompt。
- 验收：丢一个 SKILL.md 目录就多一个技能；不勾选的技能不占 token（自己验证注入逻辑）。

### M5 · 让它"记得你"（对应指南 05）
- 用一个 JSON 文件当记忆库：写入去重（近似合并）+ 简单容量上限。
- 验收：两个会话间能读到同一偏好；满上限时旧的最先被淘汰。

### M6 · 长对话不爆（对应指南 06）
- 消息超 N 条时，把最早的用 LLM 总结成摘要，替换掉（`generateText` 即可）。
- 验收：长对话不会无限涨 token；摘要放独立字段不混进消息列表。

### M7 · 守住文件边界（对应指南 07）
- 给文件类工具一个"工作区根"，越界（`..` / 绝对路径出根）直接拒绝。
- 验收：向工具传 `../` 路径被拒；`path.resolve` 后仍在根内的才放行。

### M8 · 让它自己干完一件事（对应指南 08）
- 在 loop 外加一层"多轮直到 `[DONE]`"，加轮数上限 + 连续相同输出熔断。
- 验收：目标"写个 hi.txt 并用 node 验证"能自动收敛；给个无解目标会被熔断止损。

## ✅ 毕业标准（自评表）

- [ ] 每个里程碑都过了验收标准
- [ ] 能不看代码，用 5 分钟给同学讲清楚：它怎么转（M1）、工具从哪来（M2/M4）、命令怎么管（M3）、怎么记得（M5）、怎么不爆（M6）、边界怎么守（M7）、怎么自治（M8）
- [ ] 你的注释里写的是"为什么"，不是"是什么"
- [ ] 敢把它给另一个人跑起来，然后让 TA 自己读代码

## 💡 提示

- 卡在某一里程碑时：回读对应指南那一篇——它讲的就是你正在做的事。
- 不必一次写全：M1-M3 先跑通，再逐个加 M4-M8。每加一块就**先验证上一块还正常**。
- 这是"最小"项目：`server/` 那套 SQLite/SSE/多 Agent 管理都不用做，那些是"产品化"，不是"理解 agent"的必要项。
- 做完后：把它跟 Nova Agent 的 `server/` 对照，你会看懂当初"几百行外围代码"到底是为什么。
