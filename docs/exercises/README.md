# 📘 练习册（Nova Agent 课程配套）

> 配合 [课程地图](../guide/README.md) 使用：**每读完一篇走读指南，就做对应这课的练习**。
> 这里的题全部"动手可做"——要用这个项目真的跑起来、改起来，不是空想题。

---

## 🚦 使用规则（很重要）

1. **先读指南，再做练习**：每题都基于某篇指南与对应源码，没读别硬做。
2. **先自己动手，做完才对答案**：答案分册在 `answers/` 下。**先看答案 = 白做**——"看懂"和"做得出"隔着一次动手。
3. **每题有"预期结果（自检）"**：做完对照一下，结果对得上才算过。卡住了先看"提示"，还不行再看答案。
4. **难度分级**：
   - 🟢 入门：照着做 / 读代码回答（对应指南里讲过的）
   - 🟡 进阶：小改动 / 改配置，验证你的理解
   - 🔴 挑战：综合题，需要自己想方案——最接近真实工程
5. **先跑起来再做题**：`npm install && npm run dev`，大部分题要对着运行中的系统看。
