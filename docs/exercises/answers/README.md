# 🔑 答案分册

> 与 [练习册](../README.md) 一一对应。**规则：先做题，再翻本页。** 对答案时先读"为什么"，别只抄结论。

## 使用建议

1. 做完一整课练习后，再打开对应答案。
2. 每题答案都有"为什么"讲解（对应指南哪一节）——**看答案的目的不是对结论，是补上"我哪里没想到"**。
3. 如果某题你和答案做法不同但结果对了，**也很好**——工程没有唯一解，看看答案有没有更优思路即可。
4. 如果卡在"提示"都救不了，可以只翻这一题的答案，做完剩下的再回来。
