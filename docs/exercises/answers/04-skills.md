## 练习 1：parseFrontmatter

**答案**：`/^---\n([\s\S]*?)\n---\n?([\s\S]*)$/` 中 `[\s\S]*?`（非贪婪）抓两个 `---` 之间的元数据，后面的 `([\s\S]*)` 抓正文。没有 `---` 时 `.match` 返回 null，函数返回 `{ meta: {}, body: raw }`——整篇当正文，不崩（容错）。`kv[2].replace(/^["']|["']$/g, "")` 是剥掉值两侧的引号（`"周报专家"` → `周报专家`）。

**为什么**：这是"够用主义"——frontmatter 只需要单行 `键: 值` 子集，一个正则搞定，不引 YAML 库。对应指南 04 的 §3。

## 练习 2：写一个自己的 SKILL.md

**答案**：

```markdown
---
name: 周报专家
description: 把聊天记录整理成结构化的周报
when_to_use: 用户要求写周报/总结/汇报时
---
你是周报专家。把用户的聊天要点整理成周报：按「本周完成 / 遇到的问题 / 下周计划」三段组织，用项目符号。
```

保存后技能页出现 `demo`（无需重启），勾选的 agent 会按这个口吻回答。

**为什么**：一个文件夹 = 一个技能，扫描 `skills/*/SKILL.md` 就有——"目录即安装、零注册、零数据库"。对应指南 04 的 §2、§4。

## 练习 3：目录 + 按需加载省 token

**答案**：system prompt 里只进**目录**——每个技能一行（名字+描述+使用时机），10 个技能勾 2 个也就是那 2 行的目录，正文全文不在里面。模型要用某技能时，调用 `load_skill` 工具按名字取回该技能正文（`loadSkillContent`：精确匹配 + 校验在勾选内 + 返回全文）。日志里 `skillCatalog` 拼出的字符串不会随技能多少爆炸（都是几行），因为正文根本不在目录里。

**为什么**：技能可能很多，全文全塞进 system prompt 会撑爆 token 并稀释注意力。目录 + `load_skill` 按需加载 = system 只进几行"目录"，模型用到哪个才取哪个的正文——能力上得起、token 控得住。`load_skill` 还带**条件装配**（勾过技能才注册），没勾技能就没有目录也没有工具。对应指南 04 的 §5。

## 练习 4：白名单校验

**答案**：若去掉校验，`join(SKILLS_ROOT, "../../xxx")` 会把路径拼到工作区外，`rmSync(dir, { recursive: true, force: true })` 直接递归删除——这就是**路径穿越**（path traversal）。`../` 越过目录层级、`/` 改变路径结构，二者都会让"看似在 skills/ 下"的 id 指向外面。白名单 `[\w\u4e00-\u9fa5-]+` 只允许字母数字中文连字符，从根上杜绝。

**为什么**：凡是"用户输入拼进路径"，第一件事就是白名单校验——这是本文件最该学的一行。对应指南 04 的 §6。
